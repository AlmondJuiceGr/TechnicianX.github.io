# Technician.X — περιγραφή ιστοσελίδας

## Τι είναι

Το **Technician.X** είναι ένας ελληνόφωνος ιστότοπος παρουσίασης υπηρεσιών τεχνικής υποστήριξης και ανάπτυξης ιστοσελίδων. Η αρχική σελίδα βρίσκεται στο `index.html` και είναι σχεδιασμένη ως μία ενιαία σελίδα με ενότητες στις οποίες οδηγεί το επάνω μενού.

## Τι περιλαμβάνει η αρχική σελίδα

- **Αρχική παρουσίαση:** περιστρεφόμενες διαφάνειες για επισκευές υπολογιστών, επισκευές κινητών και αλλαγή οθόνης laptop.
- **Κατασκευή ιστοσελίδων:** σύντομη παρουσίαση της υπηρεσίας και των οφελών για μια επιχείρηση.
- **QR Menu:** ψηφιακοί κατάλογοι για χώρους εστίασης, ξενοδοχεία και καταστήματα.
- **Υπηρεσίες:** επισκευή laptop και desktop, επισκευή κινητών, ανάκτηση ή backup δεδομένων και υποστήριξη ιστοσελίδων.
- **Επικοινωνία:** φόρμα μηνύματος και εμφανή στοιχεία τηλεφώνου και email.
- **Κοινωνικά δίκτυα:** σύνδεσμος Facebook.

## Περιήγηση και λειτουργίες

Τα στοιχεία **Αρχική**, **Υπηρεσίες** και **Επικοινωνία** μετακινούν τον επισκέπτη στις αντίστοιχες ενότητες της αρχικής σελίδας. Το μενού προσαρμόζεται για μικρότερες οθόνες. Η αρχική σελίδα χρησιμοποιεί επίσης εφέ κίνησης και slider μέσω των βιβλιοθηκών JavaScript του project.

Ο σύνδεσμος **WebWall** ανοίγει το `work.html`, μια ξεχωριστή ενότητα portfolio. Από εκεί υπάρχουν δύο δείγματα:

- `onlyhtml.html`: παράδειγμα με βασικά και σημασιολογικά στοιχεία HTML, πίνακα και φόρμα.
- `htmlcss.html`: παράδειγμα responsive διάταξης με HTML και CSS, Flexbox και Grid.

Το `pricing.html` είναι ξεχωριστή, απλή σελίδα με ενδεικτικά πακέτα WebWall· δεν αποτελεί ενότητα τιμών της αρχικής σελίδας Technician.X.

## Αρχεία και τεχνολογίες

- `index.html`: κύρια σελίδα Technician.X.
- `css/style.css`: εμφάνιση της κύριας σελίδας.
- `js/main.js`: slider, κύλιση πλοήγησης, εφέ και λοιπές λειτουργίες της αρχικής σελίδας.
- `images/`, `img/`, `fonts/`: εικόνες, λογότυπα και γραμματοσειρές.
- `plugins/`: Bootstrap, jQuery και πρόσθετες βιβλιοθήκες που χρησιμοποιούνται στο template.
- `work.html`, `pricing.html`, `onlyhtml.html`, `htmlcss.html`: επιπλέον σελίδες και παραδείγματα.

Η σελίδα είναι φτιαγμένη κυρίως με HTML, CSS και JavaScript. Δεν υπάρχει βήμα μεταγλώττισης ή εγκατάσταση εξαρτήσεων που να απαιτείται για την προβολή των στατικών σελίδων. Για τοπική προβολή, άνοιξε το `index.html` σε browser ή εκκίνησε έναν απλό τοπικό web server από τον φάκελο του project.

## Σημειώσεις για την τρέχουσα υλοποίηση

- Τα κουμπιά «Καλέστε Μας» και η φόρμα επικοινωνίας έχουν προσωρινές διευθύνσεις (`#`). Η φόρμα δεν είναι συνδεδεμένη με λειτουργία αποστολής email.
- Υπάρχουν αρχεία PHP, αλλά οι ρυθμίσεις email περιέχουν ενδεικτικές διευθύνσεις και δεν συνδέονται με τη φόρμα του `index.html`.
- Στο `work.html` ορισμένα έργα οδηγούν στο `html5project.html`, το οποίο δεν υπάρχει στον φάκελο.
- Το `pricing.html` αναφέρεται σε `styles/style.css`, διαδρομή που δεν υπάρχει στο project.
